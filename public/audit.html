Website quality audit

Run the local Playwright audit to check loading, images, layouts, accessibility, curriculum interactions and hyperlinks. Download the resulting PDF with status charts and a complete execution ledger.

First-time setup

pnpm install
pnpm exec playwright install chromium

Start the website

pnpm dev --hostname 127.0.0.1 --port 3210

Start the audit dashboard in another terminal

pnpm audit:serve
Open local scan dashboard ↗

Choose “Run full website scan”, then download the PDF. The dashboard opens only while the local runner is running. A published website cannot launch scripts on your computer.

Command-line alternative

pnpm audit:site

Reports and screenshots are saved under output/audits/. Automated checks have limits; review screenshots and warnings before declaring release readiness.
