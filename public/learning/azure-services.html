IMPLEMENTATION / AZURE SDK FOR .NET

Real .NET integration patterns

Use the Azure SDK where a supported client library exists. Authenticate locally with Azure CLI or Visual Studio during development and use a managed identity in Azure. Grant the identity only the required data-plane role.

✓
DefaultAzureCredential is a credential chain, not a permission grant. The selected identity still needs the right Azure RBAC role, the service endpoint must be reachable, and the workload must follow the service’s network policy. Keep secrets out of source code and prefer async APIs in server applications.
COPYABLE STARTING POINTS

Upload a blob with managed identity

Create a BlobServiceClient with a Microsoft Entra credential, then upload content to a container. The storage account must grant the app a suitable blob data role.

Identity before secrets
