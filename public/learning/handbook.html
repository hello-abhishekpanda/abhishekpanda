01 · Gradient descent explorer

The derivative tells us the local slope. Gradient descent subtracts a learning-rate-scaled gradient to seek a lower loss.

02 · Worked real-life example

Imagine adjusting a simple model that estimates delivery cost from travel distance:

ŷ = w × distance + b

Suppose the actual charge for a 4 km delivery is ₹50. If w = 8 and b = 10, the model predicts:

ŷ = 8 × 4 + 10 = ₹42

Its squared error is (42 − 50)² = 64. We can calculate how a change in the weight or bias would affect this error and update both parameters during training.

03 · From math to real code

# NumPy: a single gradient step
import numpy as np
x, y = 4.0, 50.0
w, b = 8.0, 10.0
lr = 0.01

prediction = w * x + b
error = prediction - y

dw = 2 * error * x
db = 2 * error

w -= lr * dw
b -= lr * db
print(w, b)  # 8.64, 10.16

A one-example illustrative update. Later chapters cover datasets, scaling, learning-rate selection and convergence.
