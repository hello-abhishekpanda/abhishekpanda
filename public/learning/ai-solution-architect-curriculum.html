00 / NORTH STAR

What you’re becoming

An AI Solution Architect translates a business objective into an effective, secure, scalable and cost-aware AI system. This curriculum connects programming, mathematical foundations, machine learning, advanced AI, cloud platforms and production architecture in a dependency-based sequence. It is a mastery-oriented roadmap, not an official certification syllabus.

How to study: For every important concept, explain the intuition → derive the mathematics → implement it from scratch → use modern frameworks → test, debug and deploy → defend architectural trade-offs. Follow the numbered parts: foundations → machine learning → advanced AI → retrieval → agents → durable workflows → operations → cloud delivery → solution architecture. Build a project at each stage and use its evidence gate before moving on.

    For each selected stack, study the linked tool registry, complete the project evidence gate, and record package versions and model revisions. The multimodal chapter now explicitly includes speech metrics, sampling, diffusion pipelines and memory planning.

    Memory planning: FP16 weight estimates are parameter count × 2 bytes for a single model, not the memory for a complete multimodal pipeline. KV cache, activations, runtime overhead and fine-tuning require additional memory. Start with batch size 1, a 2,048-token input limit and 256 output tokens; reduce these if needed. GPU type and availability vary in Colab. A 16 GB GPU is a useful lab target, not a guarantee of fit.
    01 · ESTABLISH

    Inspect & pin

    Record GPU memory, package versions, model revision, tokenizer, license, chat template and dataset split. Keep credentials out of shared notebooks.

    02 · COMPARE

    Run the same test set

    Measure schema validity, task success, input/output tokens, wall time and peak memory on 30 fixed tasks. Load one model at a time.

    03 · ORCHESTRATE

    One model, three roles

    Reuse one loaded model for researcher, analyst and reviewer calls. Start sequentially; distinguish logical roles from parallel model replicas.

    04 · PROMOTE

    Leave the notebook

    Move validated code into an API and workers. Run Temporal and persistent databases outside the disposable Colab runtime. Re-test the deployed model.

    For the retrieval baseline, use sentence-transformers/all-MiniLM-L6-v2 ↗ as a separate 384-dimensional embedding model. It is not one of the three chat models. Benchmark domain relevance and truncation behavior before relying on it.

    LangSmith · OpenTelemetry · usage ledger · dashboards

    LangChain / LangGraph

    Model and tool integration, agent state, routing, checkpoints and human interrupts. Keep deterministic policies outside model prompts.

    Runtime documentation ↗

    Temporal

    Long-running business coordination. Put model/network calls in Activities, design idempotent external effects, and choose one retry owner at every boundary.

    Workflow documentation ↗

    LangSmith + OpenTelemetry

    Agent-level evaluation and end-to-end operational evidence. Correlate request, workflow and agent IDs, and redact sensitive content before export.

    Tracing documentation ↗
    Autonomy is a permission level. Begin with read-only tools. Add scoped writes only after schema checks, authorization, idempotency and approval paths pass tests. More agents do not automatically improve quality; compare against one agent and a deterministic workflow.

    Token tracking is evidence. Budget enforcement is control.

    ReserveEstimate input + maximum output; atomically reserve against the shared tenant budget.
    ExecuteApply tool, step, time and output-token limits; propagate cancellation to workers.
    ReconcileUse provider-reported usage when available; label estimates and de-duplicate events.
    ReportCompare ledger totals with invoices and infrastructure spend; alert on anomalies.

    API cost model: (uncached input tokens × input rate + cached tokens × cached rate + output tokens × output rate) / 1,000,000 when rates are per million tokens. Include retries, tools, storage and GPU time separately. Use dated price snapshots; this page does not assume future provider prices. See cost tracking and gateway budgets.
